# 주차각 전시 앱

피그마 주차각 GUI를 1920 × 720 기준으로 표시하는 Flutter 전시 앱입니다.
iPad에서는 비율을 유지하고 위아래 여백을 둡니다. 지도와 주차 정보는 앱에 포함된 전시용 데이터입니다.

체험 순서: 검색 → 목적지·경로 선택 → 주차 여부 → 주차 기준 → 길안내 → 기준 변경 제안 → 주차장 선택·진입 → J구역 안내 → 3D 주행 → J-11 만차 → 출차 대기 → 새 주차 기회 알림 → 대기 선택 → J-05 재안내·3D 이동 → 후방·서라운드 카메라 → 주차 완료.

- 일반 도로에서는 지도와 차량 위치가 움직이며, 12초 후 변경 제안으로 진행합니다.
- ‘그대로 가기’의 게이지는 10초 동안 차오르고 완료되면 같은 버튼의 터치 동작을 실행합니다.
- 주차장 입구부터 대기·재안내·주차 완료까지 자동 재생합니다. J구역 전까지의 이동 속도는 유지하고, 3D 주행은 이전의 1.3배 속도로 움직입니다(이동 시간 ÷ 1.3).
- 주차장 동선은 입구 → 진입 코너 → 하단 통로 → J구역의 직선 세 구간으로 구성됩니다. 통로 중심을 따라 이동하며 코너에서만 방향을 바꿉니다.
- 차량 위치가 J구역 시작 경계(원본 지도 x=903)를 넘는 첫 프레임에 탑뷰를 완전히 없애고 피그마의 3D 시안(262:45216)을 표시합니다. 전환 시점은 차량의 실제 경로 좌표로 판단합니다.
- J구역 앞부터 주차 자리 앞까지는 3D뷰에서 계속 주행합니다. 피그마의 원본 3D 주차장과 위치 표시를 별도 레이어로 두고, 통로를 따라 위치 표시가 전진하는 동안 카메라도 따라 움직입니다. 처음 3D로 바뀌는 순간은 원본 시안과 같은 구도이며, 주차면의 차량·색상·P 표시는 원본을 유지합니다.
- 첫 안내 후에는 ‘J-11 자리가 찼어요’가 3초간 표시되고 바로 주차하지 않습니다. 피그마 14번의 3D 화면에서 5분·6분 출차 예정 표시를 8초간 보여줍니다. 분 단위 시간은 시안의 예측 정보이며 전시에서 실제로 그만큼 기다리지 않습니다.
- 다시 ‘주차각이 나왔어요’를 알린 뒤 피그마 18번 ‘주차각을 잡았어요’ 카드의 ‘다른 곳 / 계속 대기’를 표시합니다. 선택하지 않으면 6초 후 계속 대기로 이어지고, 4초 후 새 빈자리가 생깁니다. ‘다른 곳’은 새 자리 안내로, ‘계속 대기’는 대기 화면으로 연결됩니다.
- J-05가 비면 ‘주차각이 나왔어요’를 다시 표시하고 피그마 19번의 새로운 주차 자리로 3D 주행합니다. 그 구간이 끝나야 후진 카메라로 전환합니다.
- 후진 단계는 피그마 262:61880의 왼쪽 후방카메라·오른쪽 서라운드 카메라 사진을 원래 위치와 비율로 정지 표시합니다. 추가 안내창이나 가이드 애니메이션은 없습니다.
- 완료 시 피그마의 J-05 주차 완료 시안으로 전환합니다.
- 지도나 도착 정보·안내창을 누르면 다음 장면으로 바로 진행할 수 있습니다.
- 왼쪽 앱 아이콘 또는 앱 목록 버튼으로 처음부터 다시 시작합니다.

## 실행과 검사

```sh
flutter pub get
flutter run
flutter analyze
flutter test
```

화면 비교용 PNG는 아래 검사로 `build/visual_qa/`에 생성합니다.

```sh
flutter test --dart-define=CAPTURE_EXHIBITION=true
```

## 원본 에셋

`assets/figma/manifest.json`에 피그마 노드와 실제 렌더링 영역을 기록했습니다.
내보낸 PNG는 화면 경계에서 잘리므로 원본 노드 크기로 다시 늘리지 않습니다.
3D 주행용 `approach_scene.png`는 예외로 화면 밖의 원본 그림까지 내보냈습니다. 원본 노드 262:45231의 위치 표시 262:45232만 분리하고, 같은 원본 SVG를 이동시킵니다. 내보내기용 임시 복제본은 제거했으며 피그마 원본은 변경하지 않았습니다.
로고·화살표·위치 표시·안내 배경은 투명한 원본 SVG를 사용합니다.
안내 배경의 luminosity 혼합은 Flutter와 Figma에서 다르게 보여, 원본 실루엣과 투명도를 유지하며 원본 그라데이션 색상을 적용합니다.
Noto Sans KR와 Pretendard 글꼴 및 라이선스는 `assets/fonts/`에 포함되어 있습니다.
